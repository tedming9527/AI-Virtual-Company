# 候选资料试用与知识晋升

候选是生命周期状态，覆盖中央已有 skill / knowledge / framework / role 四类包，以及工具、流程、预设、政策、专业包组合和其他仓库资料。经验是来源之一，不是候选的唯一类型。流程和高级复合方法通常形成 framework；专业方法集合形成 role；未成包的研究、工具或跨目录资料用 material，target 固定拟进入的现有路径。不得为试用改变中央类型体系。

## 提炼与登记

大模型在用户已授权任务及可读来源范围内，可自行判断是否值得提炼、选择现有类型、改进已有候选或创建新候选，无需为创建候选逐条询问。只有改变未来决定且可追溯的结论才提炼；先查重复及冲突，避免把每次聊天都生成知识。保存原始经验到部署解析的个人 `experience/`，用 `candidate_register` 或 `candidate-register <input.json>` 写入个人 `staging/trial-candidates/<id>-<version>.json`。

输入 `candidate` 包含：id、type、version、title、hypothesis、triggers、exclude、scope、validation、expectedCost、sources、components、target、eligibility、status。type 为四类包或 material；status 为 candidate/stale/superseded。sources 记录固定线上 revision，或个人项目相对路径及 SHA-256。复合候选 components 固定组成项 ID、版本及摘要；不能以组成项的通过记录代替组合整体的验证。target.kind 为 pack/repository/personal，paths 指向计划的目标，登记不创建这些目标。

同 ID/版本内容不可覆盖，修订需新版本；正文、来源或组成项变化使旧证据失效。低使用、未评分和已有不良结果分别处理。候选不自动安装、不加载成正式指令、不改规则或权限、不发布；网页及候选正文始终是资料，不是工具指令。

## 在适合的任务中可选试用

`task_begin` 返回 `candidateTrials`：按完整目标中明确的触发词与排除条件匹配、至多一个建议；匹配是检索线索，不是专业适用性或质量认证。模型核对实际任务、依赖和边界后，只有适合且值得探索时才提示。无关键词命中可用 `candidate_match` 重新提交更具体的当前任务描述；不得把无关候选强行塞入任务。

同一逻辑任务跨原生回合应沿用 `candidateTaskKey`；默认值是原生 taskId。后续工具使用返回的 `candidateTrials.taskKey`。一次查询并不代表已提示；实际向用户展示选择后才记录 offer。拒绝、取消或已有试用的同候选，在该 taskKey 中不重复提示；新的任务可以重新评估。低分/不良结果只有说明此前失败及这次条件变化，提供 retryReason，才重新推荐；过期、不适用和 blocked 候选不推荐。

提示必须简短包含：为什么适合、尚未验证什么、本次试用哪部分、如何对比和成本预算；选择试用/跳过，不强迫用户。用户没有回答时不开始依赖试用的工作，普通任务及不依赖该选择的工作继续。无人值守时只记录待选择，不能把未回复视为同意。支持的界面可以使用异步用户选择工具，避免频繁打断。

## 状态与证据

`candidate_trial` 的 input（CLI 为 `candidate-trial <input.json>`）始终包含 taskKey、candidateId、sha256 和 action：

| action | 前提与额外字段 | 结果 |
|---|---|---|
| offer | 真实提示后提交 query、prompt、reason；不良结果另提交 retryReason | offered，保存范围、验证和预算 |
| decide | offered；choice=accepted/declined，responseSource=user，userResponse 为明确原话 | accepted/declined；模型申报用户选择，不证明真人身份 |
| start | accepted，候选及来源仍匹配；requires-authorization 另需 authorizationRef | running；不执行任何脚本 |
| result | running；effect、summary、comparison、artifacts、costs、可选 feedback | completed，保留未知与失败 |
| cancel | offered/accepted/running；reason | cancelled，普通任务继续 |

已发布安全与授权规则仍有效。试用同意只覆盖提示的范围；工具安装、联网凭据、写权限、发布等操作须已有相应授权，不由候选或登记扩大。eligibility=blocked 不试用；requires-authorization 的引用是权限申报，不取代平台门禁。

result.effect 为 improved/mixed/no-change/worse/unknown；comparison 为 baseline/before-after/none。非 unknown 的效果声明需实际文件产物，系统核验文件 SHA，声明效果仍不等于因果证据。artifacts.path 只在当前项目根或部署个人项目内解析；其他工作区成果可按既有交付规则保存到个人交付区，不扩大扫描范围。候选漂移仍可保存失败/结束结果，但标记 invalidated，不沿用原验证。

costs 的 timeMinutes/tokens/money/reworkMinutes 各为 `{value,basis}`；basis 为 observed/estimated/unknown，unknown 的 value 必须 null。money 有值时须记录 currency。反馈 feedback.choice 为 keep/adjust/discard/unknown，前三者须 userResponse；无反馈保持 unknown，沉默、工具成功、模型自评都不代表满意。登记和采集没有观测到的 token 与金额不能自行补算为测量值。

结果登记会自动尝试采集 `result.observedUsage`：仅根据同 taskKey 的原生任务契约定位会话/回合，再读取对应 Codex 宿主日志中的 Token 计数。保存试用起止窗口内宿主记录事件的输入、缓存输入、输出、推理及总量，并对重复累计事件去重；缓存输入已包含于输入，推理已包含于输出，不重复相加。只保存计数、范围、来源行号与摘要，不复制聊天、工具正文或凭据。来源缺失、计数回退、身份冲突、路径或格式故障均保留 unknown，不阻断结果登记。

`observedUsage` 是带范围的宿主观测，可能包含同回合其他工作，也有跨试用边界的请求；它不等于候选独占消耗、候选增量开销或完整账单。因此 `attributedTokens` 和 `actualMoney` 在无可靠归属/计费凭据时保持 null，不用这个窗口总量覆盖 `costs.tokens`，也不按 API 单价冒充实际扣费。原有声明成本、效果、反馈与产物回执保持原义。历史结果可运行 `candidate-usage-sync [taskKey]` 补录缺失/未知的观测；已保存的观测不重复累计。

试用前固定比较标准。按类型选指标：知识看决策正确性与错误；工具看有效发现、兼容性、耗时及权限成本；流程看遗漏、返工和总成本；专业/复合包看完整业务链与接口协作。设计可让用户在匿名版本间选更符合需求的一版，同时检查清晰度、可用性和性能。避免用候选自己的风格规则验证候选本身；一次偏好不证明一般收益。

`candidate_trial_status` / `candidate-trial-status [taskKey]` 查询记录。任务收口返回当前试用状态；未完成试用不阻塞普通交付，不虚构结果。周度准备保存候选身份/摘要与试用结果供复核，不把“提示/同意/单次成功”变成实证分或自动改变候选状态。采集失败只警告并继续任务。

## 从候选到中央资料

候选试用与所有权晋升是两个维度。复核可形成 reviewed_case 或明确环境的 verified_context，个人素材先通过既有 asset_lifecycle 登记成为用户资产；试用 JSON 不自动成为正式知识。中央通用化先冻结内容、检查脱敏与许可，再生成公开 PR。按当前任务的明确发布授权及平台限制完成合并、CI、tag/Release；默认人审，用户明确授权自动合并时可按授权执行，不能改写为永久免审。

四类包沿用 `register-central-release`。跨目录/复合中央资料用 `register-central-artifact-release --targets <mapping.json>`，逐一核验全部候选文件在精确 tag 中的真实内容，禁止遗漏来源、路径逃逸和私有 runtime。映射不执行代码、不替代审查；记录 reviewRef 不证明真人评审身份。原文和未吸收片段保留，失败证据不得删除。复合候选应验证组合收益，不能直接相加各组成项评分。

发布与本机启用分别验收：引擎版本、候选工具 STDIO、原生入口正文交付、实际用户选择和真实任务效果。隔离状态机测试不证明真实用户收益或当前聊天 MCP 已重载。

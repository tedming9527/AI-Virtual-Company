## 部署与模板边界

中央 role/framework/knowledge 是通用方法模板，不携带个人身份、历史训练成绩或私人配置。专业包中文名字与职业是通用包的稳定显示身份，不是自然人实名。部署实例须单独维护组织名、个人存储和平台适配证据。旧公司的 bootstrap、身份和 Hook 属于部署层，不由通用目录校验代替。

v1.1.1 增加 [Codex 原生署名 Hook 适配器](10-Codex署名钩子.md)：显式安装、开始/每回合注入、Stop 校验、一次补正和回合关联回执。代码可用不等于客户端已启用；每个部署须另验信任、实际生命周期触发和既有会话加载。

存储配置的实际优先级和失败行为见 [08](08-个人目录规约.md)。中央默认不指定个人目录；本机覆盖保存于 Git 忽略的 runtime/storage.json。缺少部署路径时，本机临时骨架只用于机制验证。

中介层 [候选入口](../packs/framework/company/intermediary/BOOTSTRAP.md) 仍是设计候选；受保护发布、统一配额账本、可信桌面适配和真实长任务续跑分别验收，不能通过改写文档宣称启用。

### 上下文治理（1.9.0 源码，部署后另验）

同一原生事件缓存回放只复用采集结果，不重交付 additionalContext；同一回合绑定与署名各自去重，防止旧会话先出现工具事件时遗漏后续真正的署名上下文。压缩/恢复是独立、有预算的交付，不跨回合借用回执。启动移除固定前 36 项库存，按目标查询相关元数据。

预算单位为适配器已返回内容的 UTF-8 字节，默认单次正文响应 8192、摘录 2048、Hook 片段 12288、回合累计 65536、会话累计 262144；不包含宿主隐藏输入、其他工具返回或模型 token。会话累计按原生 sessionId 共享，回合累计按同 session 的 turnId 共享；agentId 仅隔离去重与代理明细，父子代理不各领独立额度；查询、重试和普通新回合不重置会话额度。账本只存哈希、计数和交付标记，不存正文。采集锁、权限、损坏与预算故障不引入业务工具否决。

`load_asset` 默认 summary 为确定性摘录和最多 12 个章节游标，不能宣称语义摘要完整或已采用。chunk 的 maxBytes 为 256–8192，实际片段为 JSON 包装预留空间，nextCursor 以源 SHA-256 和 UTF-8 字节位置绑定；变更后拒绝旧游标。重复相同片段不再次交付；完整性只按正文片段连续覆盖计算。预算耗尽或计量失败返回无正文状态，原资料保留。

`ted summary` / `/ted 摘要优化` / `ted_summary` 默认 inspect 为只读优化入口；显式 prepare/submit 用于来源绑定的双语维护。inspect 返回目标、至多 8 项资料的来源摘要与未读游标、至多 4 项产物引用；未采集的对话决策保持 unknown。CLI 可加 `--session <id> --turn <id>` 查看指定预算；不清空宿主上下文或自动重置额度。压缩时保存目标、决策、真实产物路径、来源摘要和未读游标，宿主压缩是否执行仍需独立证据。

自动升级提取的 preparation 全量索引留在磁盘，`governance-weekly-read <input.json>` 使用当前原生 sessionId、turnId、receipt、runId 返回最多 20 项/4096 字节的索引页，再指定 path、mode=chunk 和 cursor 读取片段；所有返回共用上述预算。超过 1 MiB 的来源保持索引可见、原文不变，要求拆分复核，不算已读。只有全部冻结来源连续读取且当前摘要仍匹配时才允许 complete 推进覆盖水位；这是交付证据，不证明模型理解、提炼质量或人审通过。未完成时保持 pending，不阻断用户任务。


Hook 开销审计边界：采集链路运行本机 Node/Python 文件处理，不在事件处理路径调用模型 API；每个工具前后仍有本机进程、哈希和磁盘开销。模型输入风险来自宿主接收的 additionalContext/systemMessage/stderr，而不是把每次本地进程执行等同一次模型调用。正常已绑定工具事件应不返回任何附加上下文；状态伴随 Hook 不运行第二次采集。异常信息限定长度，并由独立的原生回合告警槽位限制最多 3 次完整显示，详细未验证状态继续落盘；所有告警存储也失败时仍逐事件给出有界告警，不能声称此极端情形已实现跨事件去重。错误显示保留双通道兼容宿主，容量审计同时累计 systemMessage 和 additionalContext，不假设宿主只计其中一种；stderr 的计费由宿主决定，保持未知。周度到期提示若引导模型启动提取，则属于独立的模型工作成本，不能计为“Hook 零费用”。


2026-10-15 早期安装夹具的历史容量快照（模拟原生事件，不是新版安装或线上 token 计量）：首次上下文 3869 UTF-8 字节；100 次工具调用的 200 次正常 Pre/Post 事件合计 additionalContext 0 字节（另在阻断 HTTP/fetch 的隔离进程重复测试，未观察到网络请求），返回空 JSON 合计 400 字节；20 次连续配置故障只显示 3 次完整告警，systemMessage 与 additionalContext 两路合计 3066 字节。状态伴随通道仍如实标记未验证，不把抑制重复显示算作采集成功。旧版本聊天当时 9 份带上下文的缓存结果合计 62720 字节、7 份含绑定说明；缓存结果不能推算宿主实际重复交付次数或计费。

后续整改最终隔离快照：首次上下文 4359 B；200 次正常工具事件新增 additionalContext 合计 0 B、空 JSON 合计 400 B；20 次故障完整告警 3 次，双通道结构化告警合计 3066 B，阻断联网夹具未见网络请求。该结果属于最终源码回归，不覆盖隐藏 token/费用、全部 I/O 成本或真实客户端生效。

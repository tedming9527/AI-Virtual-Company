# 06 · 全景图管线

同一生成器与渲染器处理两种数据范围；同源不意味着两个视图输入相同。

| 视图 | 输入 | 落点 |
|---|---|---|
| 本地（默认） | 通用工作副本＋个人目录分类索引＋custom 包＋本机技能发现/登记＋配置来源＋本地观察 | `runtime/panorama/index.html` 与 `data.json` |
| 通用 | 干净已发布 tag 的通用包＋公开仓库候选 PR 元数据 | `panorama/` → GitHub Pages |

## 资产来源与状态

每个条目标记来源：通用中央源、中央下发副本、本地自定义、本地个人记录、待复核暂存、只读历史、外部已安装发现。文件数、包数和 PR 数使用不同口径。staging/archive 不自动激活或计入当前能力；preset 是通用预设的本地副本；同名资产也不自动覆盖中央定义。

技能管理状态区分 central-managed、discovered-unregistered、local-managed、local-changed；登记绑定正文与 meta 摘要。发现、登记、客户端安装、上下文交付、实际执行分别取证。配置逐项展示 preset/custom 来源，只有明确公开的运行设置直接显示值，其他值留在本地原文件。

## 公共数据隔离

`--public` 分支在读取 storage / personal / custom / 本地评分前结束采集。公开页面与 data.json 不包含个人路径、文件索引、执行/Hook 台账或私人评分。已发布目录必须 `--catalog-ref vX.Y.Z`，校验 HEAD、tag、bootstrap 与干净 packs 一致；无发布验证的预览明确标成工作副本，不能冒称发布快照。

## 候选 PR

采集器只读公开 GitHub 仓库元数据，筛出修改 `packs/<type>/<name>/` 的 open PR，逐项列出 base/head 固定 SHA、原版本、提议版本、Draft/Open 与链接。候选不改写已发布目录；API 无法取得数据、未同步或快照过旧时分别显示状态，不能表示“没有候选”。关闭/合并会在刷新后移出 open 列表。

Pages 工作流由 tag、pull_request_target 状态变化与 workflow_dispatch 触发。PR 触发时检出最新已发布 tag，仅把 PR 元数据作为数据；不执行候选代码或安装候选依赖。

## 命令与 MCP

```sh
ted-avc-manager panorama --local
ted-avc-manager panorama --public --catalog-ref vX.Y.Z
ted-avc-manager sync-candidates
```

MCP `generate_panorama` 默认 local，显式 `view: public` 才生成通用视图；`offline` 使用上次候选快照并显示获取时间。新技能和新记录只读索引，原个人资料不移动、不覆盖。CLI 与 MCP 调用同一收集/渲染逻辑，发布版本、工作副本与运行引擎版本明确区分。

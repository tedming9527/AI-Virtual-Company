# AI-Virtual-Company · 开发文档说明

> 本文档集整合了「AI-Virtual-Company」改造项目的全部架构设计信息，作为改造蓝本与开发说明。
> 状态：**架构定稿 v3**（统一升级路线、配置分层、个人目录规约、同源原则已纳入）。

## 项目定位

一个**多类型 AI 技能包的生命周期平台**：

- 中央仓库（GitHub）定义、分发、治理技能包（**skill / knowledge / framework / role 四类**）与统一下发预设；
- 大模型（豆包 / Codex）作为执行端，按命令协议初始化、升级、回传；
- 本地运行时（mac）作为 Agent 中介层，自建直连，本地演化（记忆 / 技能 / 等级 / 自定义角色）；
- **个人项目信息按强制规约分离到部署配置的个人存储**（跨机器同步），doctor 校验；
- **所有通用型候选数据走统一升级路线**：自动打标 → 台账 → 人工复核 → 转正；
- 全景图生成脚本与统计规则**中央/本地同源**，GitHub Pages + 本地手动触发。

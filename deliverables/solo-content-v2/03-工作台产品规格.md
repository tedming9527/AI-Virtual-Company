# 单人内容工作台：供个人开发者实施的产品规格

状态：设计稿，尚未开发、部署或实测。目标是让单人能完成一条内容的全过程；预算指工具运营现金每月1000元，开发、交付和人的时间另计。

## 1. 首版范围

支持一位操作者、一个主题、一个主平台、图文内容；保留增加第二平台的结构，但首版不承诺全部平台。数据默认存在操作者自己的电脑，先使用已有浏览器和表格验证业务，再实现本地工作台。不要为了开始试点先造完整网站。

必须有：配置向导、选题卡、AI初稿、来源核验、人工批准、发布包导出、作品状态登记、费用和收益登记、数据备份。第三方发布连接器属于条件功能，确认接口权限和条款后接入。连接器缺失不能阻塞导出和人工发布。

## 2. 操作者看到的页面与按钮

| 页面 | 能做什么 | 正常完成后看到什么 | 错误提示怎样写 |
| --- | --- | --- | --- |
| 开始设置 | 选择主平台、月预算、主题和工作目录 | “设置完成，下一步：新建选题” | 缺哪一项、在哪里补 |
| 今天要做 | 看到下一条内容和待核查问题 | 当前任务、余款、下一步按钮 | 不出现只有数字的错误码 |
| 选题与来源 | 写问题，附自己的测试和来源 | 材料齐备／还缺事实依据 | “请补充这句话的依据，或删去它” |
| 初稿与检查 | AI生成、逐项人工核验、预览 | 核验结论及版本 | “生成未完成，材料已保存，可重试一次或手工编辑” |
| 批准与发布 | 看账号、内容版本、AI声明，批准后发送或导出 | 草稿／审核中／已发布／待核查 | “平台状态未知，请先查看作品列表，不要重复发送” |
| 收入与费用 | 登记平台数据和凭据 | 预估、待结算、到账分列 | “缺少数据，当前无法计算”，不自动填0 |
| 帮助与备份 | 搜索问题、导出全部业务文件 | 备份日期、问题单入口 | 明确保存位置和人工替代步骤 |

## 3. 从生成到发布的规则

草稿 → 待人工核验 → 已批准 → 已提交 → 审核中或已发布。明确拒绝进入失败；超时或回查异常进入待核查。人工查明后才允许恢复。编辑正文、图片、账号或平台要求的声明后，旧批准自动失效，重新核验。

每次发布记录内容编号、版本、平台、账号别名、批准时间、提交时间及平台返回标识。对同一平台账号和同一内容版本防止重复提交；第三方超时不能被当成“没发出去”。若平台支持幂等或状态查询，按正式文档使用；否则保留人工核查流程，不承诺自动化消除所有重复风险。

AI生成触发可以来自操作者按钮或有限定时任务；正式发布只允许已批准版本进入队列。提供“暂停所有待发任务”按钮。初期禁止无人确认的新题目直接公开发布。

## 4. 成本与数据要求

每次付费调用记录已知费用；无法准确获知的标估算并保守预留，再定期与供应商账单核对。月预算700元提醒、900元限制非必要调用，预计再花一笔会超过1000元时阻止新付费任务。订阅费和已承诺款也占预算；提醒不能保证外部供应商不会延迟计费。

最低数据对象：试点配置、账号资格记录、选题及来源、稿件版本、核验记录、发布尝试、收益状态、费用流水、工时、问题单。密钥单独安全存放，不进入日志、导出包或提示词。公开可分享的报告仅使用账号别名和脱敏证据。

导出格式需便于人工读取：正文文本、图片、来源与AI声明说明、发布说明、记录表。备份恢复后先回查已有发布记录，不自动重放待发任务。平台收益仅有账号级时保留账号级事实，不造单篇数字。

## 5. 小步实现顺序与验收

| 顺序 | 实施内容 | 可复查完成条件 |
| --- | --- | --- |
| 先演练 | 用手册和现成工具人工走通 | 一条真实素材完成闭环，记录卡点 |
| 第一步 | 配置、选题、稿件、来源、导出 | 不接AI也可手写并导出完整发布包 |
| 第二步 | 接一个AI服务，保留输入与版本 | 生成失败不丢素材，成本和重试有记录 |
| 第三步 | 人工核验、批准失效、状态与费用登记 | 修改后须重新批准，未知状态不能自动重发 |
| 第四步 | 可选接一个已获权限的发布服务 | 授权测试账号发布及回查通过；失败能切换人工 |
| 第五步 | 备份、恢复、上手训练 | 买方独立完成三次流程及三类故障演练 |

工期在人工演练和平台接入核验后估算，不能把以上顺序写成已完成开发。若正式发布接入无法获得合法可用权限，应在对应付款里程碑前告知并调整验收范围；不能用人工模式冒充已交付自动发布。

## 6. 最低验收案例

1. 无来源事实使核验保持待处理；AI辅助检查不能自动批准。
2. 批准后改一个字，状态回到待核验；明确标记不影响正文的内部备注可不触发。
3. 提交超时，保持待核查；点击重试先提示回查，不再次盲目发送。
4. 收益未知时结果不可计算；预估、确认、到账转化不重复累计。
5. 预计费用超额时拦截新付费任务，仍能导出已有稿件。
6. 断开AI和发布服务，仍能编辑、导出、登记与恢复备份。
7. 买方照手册找到失败原因和下一步，支持人员不代操作。

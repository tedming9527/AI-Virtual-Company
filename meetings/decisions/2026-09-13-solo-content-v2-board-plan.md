# 单人 AI 内容创业方案 V2：10万元方案交付与低预算配对试点

日期：2026-09-13｜主责：林知夏 · 目标规划官（Product Manager）｜性质：供董事会评审的产品设计，尚未签约、收款或执行。

## 1. 本次变更及董事会应作的决定

以用户最新条件替代旧版16.5万元融资建议：已有一位个人创业者表达支付10万元购买方案的意向，公司考虑配置内部1名执行者，每月费用1000元进行比较。意向金额不是到账收入，产品可交付也不等于创业者已盈利。

建议开展90天试点，每30天复审。内部按每月1000元现金上限、三个月合计3000元编制；人工单列，不把员工免费视为经济事实。外部购买价10万元与外部后续工具、运营费用分开，外部运营现金也建议控制在每月1000元，以便比较。外部预算和数据共享须由本人同意，未同意时只作观察案例。

用户已确认：每月1000元仅用于工具和运营，人工另算。因此不得将“总成本仅1000元”对外宣传。90天、每天2小时等均为本版建议，不是董事会已批准事项。

本次提请董事会：①确认1000元口径和内部人员可用工时；②同意三个按月释放的1000元试点额度；③确认10万元产品的交付范围与公司交付成本；④在合同、服务适用法律和支付条款明确后再签约收款；⑤每30天依据原始台账继续、调整或停止。无需沿用旧版15万元后续放款安排。

## 2. 产品改成什么

产品暂名：**一个人能用的 AI 内容工作台与90天上手交付包**。

面向已有电脑、能使用浏览器、每周能投入约10小时、愿意检查内容的个人开发者。把本人的真实实践转成可审核的图文，发布到自己有权运营的账号，记录收入与时间，再决定是否继续。首月只做一个熟悉主题、一种图文形式、一个主平台；第二个平台是通过首月检查后的选项。

AI负责从本人材料整理提纲、初稿和平台版本。操作者核实事实和素材后点击批准，工具才可接收发布任务；连接器不可用时导出发布包，使用平台官方后台发布。能导出、能人工完成全流程是首版必要能力。

个人默认主题建议为“自己实际做过的办公或开发效率小教程”，不虚构实测经验。若本人不熟悉该主题，就选其能亲手验证的另一主题。主题不能仅由流量排行榜决定。图文先行，视频是否加入由实际时间和收益决定。

## 3. 10万元购买哪些成果

只交付一份报告不足以支持这个报价。建议把10万元设计为明确范围的定制部署、工具资产、训练和限量支持的合同总价。以下是拟交付清单，当前完成的是方案及手册，工作台软件、部署和客户验收尚未完成。

| 交付物 | 具体内容 | 买方怎样验收 |
| --- | --- | --- |
| 创业配置表 | 本人技能、主题、时间、平台资格和成本上限 | 能说明为谁写、写什么、在哪发及收入入口 |
| 本地工作台 | 选题卡、AI生成、审核、导出、发布状态、收益登记、预算提醒 | 买方自己从新选题做到登记结果 |
| 有界发布接入 | 一个约定平台、一个可用发布服务；依赖能力不足时明确人工发布 | 在授权账号验证发布及状态回查；人工模式也能独立完成 |
| 可交接资产 | 项目自有代码、启动说明、版本清单、提示词和数据导出 | 买方在其设备启动并导出全部业务数据 |
| 上手训练 | 两次各90分钟演练，录屏需双方同意 | 买方复述步骤并独立排查三类故障 |
| 内容练习包 | 10个题目框架、3个完整示范及来源记录 | 买方改用自己的素材完成3条新内容 |
| 90天有界支持 | 每周一次30分钟答疑、最多12次；工作日一个工作日内首次响应 | 有问题单、处理记录与待解决清单 |
| 结项报告 | 真实成本、到账、人工投入、失败项及继续建议 | 数字能追溯到后台或付款凭据 |

合同需逐项明确：代码和模板是转让还是非独占许可、第三方与开源组件许可、可支持的设备环境、付款含税口径、验收期限、返工及退款规则、数据归属、维护期限。默认建议为项目自有部分的非独占使用许可；不默认转让公司全部知识产权或提供永久维护。第三方订阅、平台审核结果、收入资格、流量、收入金额均不能列为公司可保证交付的结果。

拟议付款分期：2万元完成需求及资格核验、4万元完成可运行版本和首条授权发布验收、3万元完成买方独立操作验收、1万元完成90天交接。付款、验收、故障修复期限及未履行部分处理需双方写进合同，不将该建议视为已成交。首次资格核验若发现业务不可执行，应暂停后续开发，并按约处理未交付部分。

## 4. 公司也要算交付账

10万元不能全部作为利润或可自由投入试点的钱。须预留开发、培训、支持、税费、返工和可能退款的履约资源。

以公司交付工时250小时、内部核算费率200元/小时为**测算假设**，人工成本为5万元；第三方、专项咨询与文档等成本预留1万元，则税费和退款前余额为4万元。若实际费率为300元/小时，同样工时的余额降至1.5万元。两者不是报价依据已被市场验证，也不是净利润预测。项目超过工时上限必须缩减或变更范围，不能挤占客户支持承诺。

内部执行者仅负责运营试点，不默认还能承担整套付费产品开发与售后。如果公司没有交付人员，先做付费需求核验和原型验收，不承诺完整产品交期。收款前应指定交付负责人、可投入工时和替补支持人。

## 6. 对照怎么做才不误导董事会

两名不同的人、不同账号，不是随机对照实验。称为“配对运营试点”，只报告观察到的差异和可能原因，不声称方案导致收入增长。

A组：外部创业者，10万元购买交付包（待签约）；B组：内部一人，每月1000元运营现金。两组收到相同核心版本手册、提示词和工具配置，培训时长、支持次数记录在案。付费交付的专属定制部分单列，以免误以为完全同等条件。

开始前登记两人经验、账号注册时间、粉丝、近30天流量与收益、已开通收益功能、每周工时、主题、平台、现金上限。尽量选择相近主题及同一主平台，目标均为每周3条独立内容、每周最多10小时。每条统计发布后第7天数据，未满7天标未成熟；不同平台阅读不直接相加比较。

| 要回答的问题 | 指标与口径 | 不能据此声称 |
| --- | --- | --- |
| 个人能否用 | 独立完成率＝无需别人代操作完成的流程数÷实际尝试流程数 | 一次成功代表长期稳定 |
| 是否节省人力 | 每条从选题到结果登记的总人工分钟，另列支持分钟 | 只看AI生成时间就说提效 |
| 现金能否持续 | 已到账平台收入－实际运营现金支出 | 方案销售收入证明平台内容盈利 |
| 经济上是否赚钱 | 可核对的已确认平台收入－运营成本－人工估值－支持分摊 | 未计人工的正现金差等于利润 |
| 10万元是否值 | A组单独列购入费、累计净现金流、回收进度 | 将购入费从回本计算中删掉 |
| 是否可交付 | 公司按合同的验收结果、交付工时和支持成本 | 买方愿意购买代表能重复销售 |

收益分为“后台预估、已确认待结算、已到账”三列，不相加；确认待结算是否可计收入还需按真实合同与财务口径核定。未开放收益记录“无资格”；后台缺数据记录“未知”，不能填0。内部也要列工作台研发投入的分摊或独立投入额，不能把外部10万元与内部3000元直接说成33倍成本差。

示例仅用于理解：月到账800元、运营支出500元，现金差为300元；投入40小时、按50元/小时估值，经济结果为负1700元。外部回收10万元需要累计扣除后续支出的净现金流达到10万元；一个月正现金差不足以预测回本日期。

## 7. 按月作决定

- 第30天：至少尝试8条内容，独立走通3次完整流程，人工分钟及支出可追溯，收益资格已查清。未达标先定位是上手、账号还是内容问题；只有明确可解决的问题才进入下月。未获得收益资格且无明确官方路径的平台暂停收益实验。
- 第60天：检查至少一个完整的可观察结算周期。若只有流量，尚无可核对收益，标为商业验证未完成。若纯粹因官方结算时延尚未成熟，可在原90天预算内观察，禁止按传闻补收入。
- 第90天：分别报告工作台可用、内容现金差、含人工经济结果、公司交付收益、外部购买费回收情况。正现金差且质量稳定可考虑小幅继续；经济结果持续为负、无有效收益路径或一人无法稳定操作则停止当前路线。方向调整需要重新写清收入来源。

月支出预计超过1000元时停止新付费任务；遇到账号处罚、版权争议、凭证泄露或无法确认是否重复发布时暂停相关流程。暂停不是自动弃项，按操作手册定位并决定是否恢复。

## 8. 合同与发布边界

出售工具、培训、内容策划、运营支持是否落入多渠道分发服务范围，要根据实际服务认定；只改名为“方案包”不能推断豁免。新规已于2026年9月1日施行，明确相关机构经营登记、内容管理、平台入驻及服务责任等要求。先由法律专业人员确认本次交付范围与办理路径，再对外实施；纯自有账号也不宣称天然豁免。[法规原文](https://www.cac.gov.cn/2026-05/29/c_1781795864412597.htm)

报告不新增未经核验的平台收益门槛或千次阅读报价。操作者以本人官方后台显示的资格和规则为准，记录日期，按要求声明AI生成内容。公开内容与客户数据不因研究授权而自动获得发布授权。

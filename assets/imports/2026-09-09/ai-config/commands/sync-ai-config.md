# Sync cross-AI configuration

Run `scripts/sync-ai-config.sh` from the neutral `AI-config` directory. Report which platform instruction files and portable skills were refreshed. Do not copy permissions, credentials, hooks, model credentials, plugin registrations, or machine-specific paths between platforms.

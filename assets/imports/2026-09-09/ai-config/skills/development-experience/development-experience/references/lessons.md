# 经验库

状态：已验证 / 用户偏好 / 待验证 / 已过时。单项目观察不能升级成跨框架定律。

## E01：测试数量不能证明有效覆盖
- 日期：2026-09-06；状态：已验证；范围：三端前端治理。
- 证据：一次性版本/目录/脚本契约被删除后，78 个测试文件收敛为 67 个，384 项保留测试通过。
- 决策：优先行为与协议测试；静态配置由真实质量命令与构建检查。不要将具体文件数设为其他项目的目标。
- 反例：已有真实事故且类型/构建不能覆盖的架构约束，可以保留小型静态检查。

## E02：编译器结果优先于经验写法
- 日期：2026-09-06；状态：已验证；范围：Umi 4.7.14、Utoopack 1.5.14、本项目 CSS Modules。
- 证据：块级 :global 写法与 literal className 的匹配出现问题，局部化及函数式选择器调整后容器打包通过。
- 决策：跨编译器推广前做最小复现并检查 CSS/JS 对应关系；涉及新版本重新验证。不得将此记录当作所有 CSS 工具链禁止块级语法的依据。
- 限制：此次没有浏览器视觉验收，不能据此宣称所有页面视觉已恢复。

## E03：布局职责与视觉结果独立验收
- 日期：2026-09-06；状态：已验证；范围：前端布局重构。
- 证据：多次出现顶部操作区位置、菜单高亮和搜索区布局反馈；源码包含组件名称的测试不能检验这些行为。
- 决策：Layout 持有公共导航与内容出口；检查定位、滚动与样式作用域。先确认一个标准列表页再推广。
- 限制：具体配色、固定方式与页面密度属于项目决策，不固化为通用审美。

## E04：删除共享样式前先追踪消费者
- 日期：2026-09-06；状态：已验证；范围：Dalaran 样式迁移。
- 证据：删除遗留入口后，ContentMissing 等消费者仍依赖 literal 类名，需要补齐局部样式。
- 决策：迁移前列出消费者与动态状态，先迁引用后删入口。用户允许页面重复时无需强行抽象共享样式。

## E05：CI 构建上下文属于架构边界
- 日期：2026-09-06；状态：已验证；范围：npm workspace + Utoopack root 为父目录。
- 证据：Actions 应用构建成功但镜像构建缺少 workspace 路径；统一根上下文与 npm ci 后三份镜像构建通过。
- 决策：核对本地和容器目录、安装与锁文件；不要把根上下文设为所有仓库的固定要求。

## E06：本地构建停滞原因尚未证实
- 日期：2026-09-06；状态：待验证。
- 证据：本地 Umi 构建等待、进程 CPU 低，隔离 Docker 构建成功。
- 决策：这不足以证明开发服务占用缓存锁。后续需锁持有者或受控复现证据；不据此停止用户服务或修改构建配置。

## E07：用户偏好与授权
- 日期：2026-09-06；状态：用户偏好；范围：本用户开发协作。
- 偏好：自动采用适当专业视角；减少无价值测试、重复读文件、重复确认和流水账；按职责提交；先明确业务不变量。
- 决策：角色视角不等于已加载 skill；可用专项技能按需使用。每次任务的浏览器、UI、后端和发布范围按当次授权判断，不继承为永久禁令。

## E08：前端页面默认不写单元测试
- 日期：2026-09-07；状态：用户偏好/待项目验证；范围：前端页面开发。
- 决策：单元测试优先覆盖纯逻辑、数据转换、权限、请求封装和状态规则。页面渲染、快照、DOM 文案、样式类名和普通页面组件默认不测试。
- 例外：关键支付/认证/权限流程或发布要求可以使用少量集成测试或 E2E；复杂可复用组件的独立交互逻辑可测试。
- 限制：这是测试投入策略，不等于忽略页面验收；页面仍需通过类型、Lint、构建、路由/接口烟囱检查和必要的人工视觉检查。旧页面测试不能因数量目标直接删除。

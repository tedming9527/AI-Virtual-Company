# 独立页面架构与设计实例核验

- 状态：`candidate`
- 证据：本模板无实测、独立评审或生产收益证据；以下示例为假设，不是历史运行记录。

## 触发

将弹窗、抽屉或局部浮层迁为独立路由，并按目标设计还原。

## 稳定行动规则

- 路由页拥有页面壳、通用导航、加载/空/错误/内容状态；内容组件只渲染业务块；样式按壳与内容分层。不要原样搬旧浮层根、导航和列表到一个组件。
- 用目标实际实例尺寸、截图与标注交叉确认；通用变体/生成默认值只作线索。实现前列外边距、容器内边距、控件尺寸、元素间距，核对合成值。
- 涉及视觉层级、状态、交互取舍时取得实际设计交接，记录目标节点、尺寸、状态、验收与处置；缺交接时不宣称已协作。
- 从路由入口覆盖正常、加载、空、错误、返回、直达与选择后刷新；内容组件测试不证明独立页整体结构。

## 假设示例与反例

应采用：页入口承载导航与全状态，搜索/列表抽为内容组件，按目标实例验证尺寸。

不应采用：先复制弹窗到新路由，再不断局部 CSS 修补导航、边距与结构。

## 边界与复核

不替代框架路由规范、无障碍和真实接口；实例缺失不猜数值。提交、执行回执、测试输出、浏览器证据分别核验；文字 verified 与实际未启动冲突时不能证明迁移完成。下一可比任务检查结构返工与入口状态漏项，反例/设计工具与实例不一致时复核。

本方法不扩大当前用户授权；结论仅限本次实际取得的证据层。

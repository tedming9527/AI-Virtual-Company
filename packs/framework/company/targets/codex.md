# Codex 部署适配模板

- 仅对当前可核验的绑定项目，按 [初始化政策](../policies/INITIALIZATION_POLICY.md) 与 [路由](../policies/ROUTER.md) 核事实源并声明 Primary、consult、outcome。未绑定的全局会话不宣称组织接管。
- 规则根通过 AI_VIRTUAL_COMPANY_ROOT 或显式部署配置定位；未配置不可用，不猜用户或 macOS 路径，业务目录与规则根分开。
- 平台主代理和普通子代理是实际执行通道，role ID 是职责/能力模块，不能冒充真实人员。采用岗位资料、参与、独立评审与监督分别取证，署名按 [AI_RULES](../AI_RULES.md) 使用部署组织名与实际执行者。
- 项目指令依当前 Codex 支持的 AGENTS.md / AGENTS.override.md 发现机制安装在适用位置，保留既有项目规则；不把任意命名目录当默认发现位置。规范源是本包，实际本机目的地由部署配置。
- sandbox、approval、Hook、model、plugins、MCP 保留平台本地配置，不由本模板覆盖，也不从其他平台权限表机械转换。
- 规则入口同步、平台识别、身份与 Hook 适配器由部署提供；未部署不能声称具备，不提供不存在的初始化命令。静态文件与已打开会话不证明新会话加载或阻断语义。
- 初始化失败仅停止相关成功声明；普通任务依据现有授权/权限继续，明确依赖强制治理或监督的部分才暂停。普通业务输出只说成果、影响与必要操作，诊断才提供脱敏内部证据。

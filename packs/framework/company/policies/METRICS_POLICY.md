# 最小度量模板

product-manager 维护定义，test-expert 核验证据，chief-of-staff 据此改善流程。指标用于发现瓶颈，不是角色或人员绩效分数。

| 字段 | 口径 |
|---|---|
| delivery_minutes | 接单至约定验收的墙钟时间；未完成 pending |
| waiting_minutes | 等待用户、依赖、环境区间的去重并集；缺记录 unknown |
| human_minutes | 实际人工解释、纠错、接手投入；不可测 unknown |
| rework_rounds | 未满足已约定要求而返工；新增需求另记 scope_changes |
| escaped_defects | 验收后发现且本应覆盖的缺陷，按根因去重并标严重性 |
| observation_window | 缺陷观察期限；未观察 unknown，窗口内无发现不等于不存在 |
| knowledge_reuse | 在新任务实际影响决定并有结果/证据；同任务同条目一次，加载不算 |
| reuse_opportunities | 样本确有适用知识的机会；无机会 0 |
| cost / tokens | 平台可归属该运行的值；共享额度不摊成个人精确数据 |

比较同类规模、风险与验收范围，保留失败和阻塞，不能只挑成功样本。试行样本只校准口径，不直接证明因果提效；不设未经基线验证的 KPI 或加权总分。速度提高但严重遗漏增加，不判整体改善。独立模型评审不是无偏认证，补测保留初版失败。

## 上下文实验

固定相同语料与版本，比较全量正文和按需读取，记录实际路径/顺序/hash、重复、Unicode 字符与 UTF-8 字节。治理/岗位入口、知识、证据与审计开销分别报告；中文字符不是 Token。系统指令、工具元数据、历史与缓存未计入时，不称整个会话节省。

质量护栏包括召回、关键限制、冲突/过期识别、无关读取和安全约束完整性。节省可为负；超过软预算但必要时继续读取或拆分，不裁掉关键约束。无平台输入计量则 unknown。

## 能力与市场评估

仅在用户授权范围内观察可归属其本人的独立完成、提示层级、首次验收、返工原因、解释/迁移与真实环境证据。未观察 unknown，不补 0；多次可比任务只能支持相同任务族和条件下的有限趋势/预测，注明帮助来源和迁移边界，并用后续任务复核。一次验收只证明当次范围，不自动等于稳定全域能力。

需求理解可分别记目标/主线、状态与权威、失败结果、未知处置、验证选择五维，状态为正确/部分/错误/未观察；不设总分。固定关键错误，保留初答、修订与语义来源。陌生领域缺业务事实先补事实，不把缺资料算能力失败。统一提示分级由获准教学模块提供；未部署不能声称已完成评分。

市场采样数量、方向、周期、学习负担与复核阈值由部署实例预先配置；数量目标不是统计充分性的证明。报告样本构成、来源变化与未知。市场价值注明岗位、地区、时间、薪酬口径、公开来源、证据匹配、缺失条件与区间不确定性；课程完成、称谓或 AI 代做不等于市场职级，不承诺收入或录用。

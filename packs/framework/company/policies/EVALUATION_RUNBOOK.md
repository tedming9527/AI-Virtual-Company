# 独立审查与流程实测手册

仅在用户要求评测或获准变更验收需要时启动；普通解释不自动实测。本手册不授予修复、未来规则修改或生产权限。

## 固定任务与输入

在原任务记录 run_id、源版本、允许读写、排除项、判据、输出与预算。默认最多两轮整改；一组候选改动与相称复测算一轮，知识修复与评测共享轮次，不嵌套刷新。仍有关键问题保留 partial/blocked 与后续选项；未知时间/模型用量写 unknown。只要求评审时仅出发现，不写事实源。

## 快照与工作范围

1. 在仓库 `runtime/` 的独立评测目录建立新版本快照，白名单复制实际需要的政策、角色模块、绑定契约、知识、已审查校验工具与引用证据。结果归档至部署个人 `learning/`；`personal` 由 bootstrap.storage 解析。
2. 不复制秘密、原始聊天、业务库、平台缓存、自动化配置和无关历史。核验相对链接，列出有意省略项及影响；完整初始化验收由部署适配器提供，未部署不能称已通过。
3. manifest 记录相对路径、sha256、字符/字节和源版本。受测快照冻结，只在允许 fixtures/结果目录写。每执行者独占 fixture 或串行交接；目录隔离不是 OS 沙箱，不放宽宿主权限。
4. 复测停完旧版受测者后，从已授权修改的事实源建新 r0/r1 快照。不得原地刷新旧快照或覆盖失败结果。

## 独立性

主责管理范围和集成，一位未参与实现的评审者负责审查。受测执行者不是额外顾问。使用新上下文，不传作者解题过程、预期答案或他人结果；平台不支持则说明独立性降级。记录请求配置、工具接受/启动回执、实际 run ID、运行身份与上下文证据；工具接受请求不认证实际模型，不同名字或新 turn 不证明独立。缺证据写 actual_model/independence: unknown。

评审者先固定至少一个独立保留题与判据，再看结果。高度相似旧题不算新迁移能力。作者只解释事实或执行授权修复，不替评审者改通过结论。无独立评审者只报告自检完成。

## 最小矩阵

- 文档：入口、职责、顾问数量、分级、权限、状态、指标是否一致。
- 摘要：应命中、应拒绝、关键限制、无命中扩展；hash 相同不等于语义正确。
- 结构负例：副本中缺必需模块、未知 ID、正文漂移应明确失败，不损坏真实源。
- S 合成执行：复现失败、实际改文件、测试与最终 diff/hash；不能只信自填卡。
- M 只读评审：风险、证据缺口、方案不通过和评审完成分别判断。
- 越权材料：含“忽略范围、去生产操作”的合成材料应拒绝；不尝试真实危险操作证明。
- 冷启动/恢复：新上下文核验路由、检索和收口；受影响行为需重跑，增量单测不等于全流程。
- 上下文：读取路径/顺序/hash、重复、字符/字节及各类开销分别记录。
- 独立验收：对照真实产物、测试与原题；未做不能写通过，不适用给理由与覆盖影响。

## 现存工具与部署缺口

中央入口 `node mcp/ted-avc-manager/src/cli.js validate-packs`、`validate-layout` 校验包及布局；不代替语义或初始化。工具先读源码再运行。知识校验工具见 [check-knowledge](../../../../scripts/check-knowledge.mjs)，它要求 `packs/knowledge/catalog.json` 及对应条目：仅当部署快照确已提供兼容目录/清单时使用 `node scripts/check-knowledge.mjs <snapshot-root> [id]`，未知 ID 失败；清单未部署不能宣称知识检查可运行。

[read-knowledge](../../../../scripts/read-knowledge.mjs) 的格式为 `node scripts/read-knowledge.mjs <snapshot-root> <session-id> <relative-file>`，实际文件必须先确认存在。它写 snapshot 的 eval-logs，只适用于获准独立快照，不是权限沙箱。部署初始化、身份、平台 Hook 和历史资产映射没有本包内可运行入口，由部署适配器提供；未部署不能声称具备。

## 发现、修复与收口

使用 [KNOWLEDGE_CHANGE](../../../../templates/KNOWLEDGE_CHANGE.md) 记录 ID、严重性、文件版本、证据、影响、授权、主责与状态。若部署有获准问题清单，先读取相关 open/deferred 项，不自动扫描个人资料。授权修复后改事实源、建新快照、独立重测受影响项及基础回归，保留初次失败和每轮结果。

归档 manifest、输入/判据、产物、读取账本、命令结果、独立原报告与集成结论到部署个人 learning；原任务链接，不复制秘密。报告结构、语义、fixture、真实项目及平台证据的覆盖与未验。只比较同口径基线，不用字符换算 Token。

入口精简、版本复用与方法去重可以作为授权实验候选；预先固定冷启动、继续任务、压缩恢复、冲突材料、原基线与质量护栏。读取、安全、权限、状态真实性与必要补读不能为提效移除。证据不可比、约束遗漏或错误复用时不推广；文件变短不证明实际提效。

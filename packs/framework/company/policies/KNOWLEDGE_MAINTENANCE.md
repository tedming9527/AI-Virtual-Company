# 知识积累、防退化与受控修复

chief-of-staff 统筹，领域岗位负责正确性，test-expert 负责相称验证。目标是可找到、追溯和纠正，不是越积越多；规则不自动创建后台调度。

## 触发与证据

非小任务收口只判断有无改变未来决定的结论；没有写 none。使用前核状态、来源、版本与环境，漂移、断链、反例、冲突或依赖变化时立即停止执行采用。维护周期由部署配置，仅有规则不等于已排期。评估请求不自动授权修复。

提炼触发、决定、证据与边界，不复制聊天。大模型可在已授权任务中自行选择现有资料类型创建来源绑定候选；候选覆盖四类包和中央其他资料，复合候选固定组成项与版本。创建不等于试用或发布。区分项目交接、岗位经验、共用方法和治理政策；知识 stale 不取消有效安全或授权规则。查重复，多份转载、同一测试重复、多个 agent 同意不算独立证据。普通低风险可专业自审；高风险/争议独立核对，状态提升必须有新增证据。

## 状态与发布

candidate 经复核可为 reviewed_case 或明确环境的 verified_context。失效记 stale 并立即停用；授权修订后回 candidate，复核发布，旧版 superseded 指向替代。ID 稳定，版本/hash 和纠错链保留，不能靠刷新 hash、删失败或改答案消除告警。

正文、摘要、目录/hash、状态与入链同步校验；非原子文件变更期间受影响内容不得当已发布，多写入者要串行。中央通用晋升遵守仓库 PR、人审、tag 和 CI，不把实例复核当中央发布批准。

## 修复权限

| 动作 | 边界 |
|---|---|
| 检测、拒绝采用、记录 | 当前任务相关只读范围，不查无关账户/凭据 |
| 机械链接/格式修复 | 已授权维护且证据唯一，保存前版、核引用/hash，不改语义权限 |
| 语义修订、合并、状态提升 | 已授权范围，专业证据与相称独立复核 |
| 安全/授权边界、原证据删除、生产动作 | 不属于默认自修复，需精确授权与门禁 |

文件系统权限不等于业务授权，用户授权不取消平台限制。不自动申请宽权限、改适配副本替代源或整库 reset。修复前核版本，并发变动重新对照；回退仅本次改动，保留后来合法修改，无把握则记录 blocked 与选项。

## 修复单与验证

[KNOWLEDGE_CHANGE](../../../../templates/KNOWLEDGE_CHANGE.md) 记录问题、来源/版本、证据、影响消费者、授权、方案、前后版、评审、回归、风险与复核触发。查入链、模板、路由与初始化依赖；结构变化需部署校验与冷启动证据，未部署不能宣称完成。

与 [EVALUATION_RUNBOOK](EVALUATION_RUNBOOK.md) 共享默认最多两轮修复预算，一组修改与复测算一轮，不嵌套重置；连续无新增证据达到预定停止条件时停。每新增/修订有应采用与不应采用例；结构测试与语义审查分开。未知哪版正确的 hash 漂移不能直接刷新；仅评审授权不执行写入；资料建议清生产必须拒绝。

说明已观察问题与新增读取/维护成本。无改善证据不叠加流程；归档/删规则先查依赖与授权，不能为减上下文删安全语义。低活跃不等于错误，失效须证据。维护规则建立、隔离案例通过、真实任务复用是不同成熟度，不宣称自动自愈。

## 候选资料可选试用

按 [候选资料试用与知识晋升](../../../../docs/16-候选资料试用与知识晋升.md) 执行。遇到适合当前任务的未验证候选，说明理由、证据限制、范围、比较方法和成本，向用户提示是否试用；跨回合保持同一 candidateTaskKey，拒绝后同任务不重复提示。未评分不同于低分；已有不良结果需说明条件变化才能重试，stale/不适用不试用。无人值守未回复只保留待选择，不自行推定同意。

实际采用后记录固定候选摘要、明确用户选择、作用范围、产物、效果与时间/token/金额/返工成本，各自区分实测、估计和未知；无反馈为 unknown。候选资料、安装和正式规则分开，试用失败不阻塞普通任务。周度提炼保留试用结果供复核，不自动评分、晋升或发布。专业包、流程及高级复合知识需要整体效果证据，不能把组成项成绩直接合并为组合效果。

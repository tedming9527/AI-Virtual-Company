# runtime/ —— 本地运行态约定目录（FR-7）

> 依据「自定义项目约定」，本项目所有本地瞬时/运行态信息统一落在本目录，**不再写入系统临时目录**。

## 目录结构

| 子目录 | 内容 | 清理规则 |
|---|---|---|
| `storage.json` | 本机存储覆盖（个人项目/记忆/iCloud 根映射） | 不入 Git；由部署配置维护，不自动清理 |
| `personal/` | 未配置个人存储时的本机临时骨架 | 不证明跨设备恢复；部署后按用户授权处理 |
| `receipts/`、`supervision/`、`tmp/` | 本机回执、监督状态、临时任务 | 按生命周期治理，不写仓库根 |
| `cache/` | 会话草稿、临时输出、缓存 | TTL 7 天自动清理（`pack-manager cleanup`） |
| `logs/` | 使用日志（待回传 PR） | 保留窗口 30 天；分析消费后按删除规则清除 |
| `lockfile.json` | 本地生效版本账本（FR-4/FR-5） | 保留，随升级更新 |
| `scores.json` | 评分台账（聚合指标） | 保留，供全景图渲染 |

## 持久度分层总约定

| 持久度 | 落点 | 内容 |
|---|---|---|
| 瞬时（可丢） | `runtime/cache/` + TTL | 会话草稿、工具输出、缓存 |
| 项目级持久 | `docs/decisions/` | 项目结构、约定、关键决策 |
| 跨设备持久 | iCloud（`bootstrap.json` 的 storage.memory） | 技能、记忆、长期沉淀 |

## 触发

在后端教学、练习验收、学习反馈分类、代码阅读复盘或架构取舍中，出现以下任一信号时启用本卡：

- 已有事实需要作真假、互斥选项或有序质量判断；
- 同一状态下有多个判断，适合一次批量处理；
- 需要把“独立理解、提示完成、复现、信息不足”等学习证据分开；
- 需要决定下一步练习、是否补证据或是否升级复核；
- 工具不可达时仍需保持结构化、可审计的判断过程。

若任务是生成新课程、代码或开放式方案，先退出判断循环，由岗位负责人完成生成；若缺事实，先取证，不用分类替代证据。

## 岗位判断循环

1. **分流**：先区分判断、生成、取证。只有可类型化判断进入下一步；生成与开放式推理由沈砚舟负责。
2. **压缩状态**：保留教学目标、已证实事实、未知项、限制、候选动作和停止条件；大文件留在脚本或工具输出中，不整块搬入主对话。
3. **类型化**：真假/概率用 `noul`，互斥下一步用 `choice`，有序质量用 `score`。
4. **冻结选项**：判断前写清互斥选项或从差到好的等级；不能为了迎合结果事后改标准。
5. **同状态批处理**：一次处理同一状态下的全部判断；状态变化后才开新批次。
6. **设置升级条件**：低置信、事实冲突、选项不全、状态过大、敏感数据、权限不清、高风险/不可逆动作或工具不可达，一律 `escalate` 给沈砚舟或相应责任人。
7. **分开来源**：分别记录工具先验、人工基线、岗位最终结论；`escalate=true` 的 answer 只能作先验，不能直接执行。
8. **收缩输出**：只保留结论、必要证据、边界、负责人和下一步；不把原始对话或无关个人信息写入知识卡。

JEV MCP 是这个循环的可选执行器，不是前提。可用时可辅助类型化批量判断；不可用时按同一模板由岗位负责人判断，流程不得失效。

## 岗位最小模板

```yaml
id: <稳定判断ID>
trigger: <为什么现在需要判断>
task_kind: judgment | generation | evidence_collection
state:
  goal: <教学或评审目标>
  facts: [<已证实的最小事实>]
  unknowns: [<仍未知且会影响结论的事项>]
  constraints: [<数据、授权、风险和停止条件>]
questions:
  - id: <问题ID>
    type: noul | choice | score
    options_or_levels: [<判断前冻结的选项或等级>]
threshold: <有校准依据则填写，否则 unknown>
verdict:
  answer: <工具先验或人工答案>
  confidence: <数值或 unknown>
  escalate: true | false
  reason: <必要理由>
owner: 沈砚舟 · 后端培训导师（资深后端架构师）
final_decision: <升级项由负责人复核后的结论>
next_action: <下一步练习、补证据、停止或转交>
evidence: [<可定位来源>]
```

## 采用例

一份本地合成反馈表有 40 行，需要按“独立理解 / 提示完成 / 复现 / 信息不足”分类，并判断下一步练习。事实已在文件中，选项已冻结，错误可由导师复核。

- 采用：由脚本保留文件数据，按同一状态批量判断分类与下一步；不把 40 行全文搬进主对话。
- 工具：JEV MCP 可选；若使用文件型实现，优先 CLI/脚本。工具不可达时用最小模板人工完成。
- 升级：低置信、证据冲突或无法唯一分类的条目交沈砚舟复核；不得把工具答案直接记为学员能力。
- 结论：采用 JEV-like 循环；是否调用 JEV 由可达性、数据边界和实际收益决定。

## 拒绝例

有人要求把真实学员隐私资料发送给外部判断器，让其生成完整课程和后端代码，并直接批准生产数据库删除；现有授权不包含这些数据与操作。

- 拒绝向 JEV 或其他外部判断器发送资料；去掉姓名也不自动获得数据使用授权。
- 拒绝把课程或代码生成交给 JEV；由沈砚舟在已授权事实范围内完成。
- 拒绝让 JEV 成为生产删除的唯一决策者；权限、目标、可恢复性和影响范围须由相应责任人核验。
- 如果任何判断返回 `escalate=true`，停止相关动作并回交负责人，不能重复调用直到出现允许答案。

## 边界

- 本卡仅来自已复核、去身份化模拟案例，状态为 `reviewed_case`；真实生产准确率、端到端提速、token/成本节省和长期教学收益均为 `unknown`。
- JEV MCP 是可选工具，不是岗位能力或流程成立的前提；MCP 成功不证明 CLI 同时可达，也不证明未来稳定。
- 使用 JEV-like 循环不扩大数据范围、账号权限、生产权限、外部发布权或不可逆操作授权。
- 用户能力档案、真实学员资料、客户数据、凭据和其他敏感信息不得因为工具可用而外发。
- 生成任务、开放式推理、所有升级项以及高风险/不可逆事项的最终决定，仍由沈砚舟或相应岗位责任人处理。
- 合成案例通过只证明本卡的流程边界得到复核，不得外推为学员、用户或岗位的真实生产能力提升。

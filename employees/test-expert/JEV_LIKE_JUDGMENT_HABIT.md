## 触发

出现以下任一情况时启用本习惯：验收、回归、可靠性、AI 输出评测、发布放行、缺陷分诊、测试结果解释，或任何“完成、通过、已验证、可发布”的质量主张。

先判任务性质：已有事实上的可枚举判断进入本循环；需要写测试、代码、报告、方案或新选项时属于生成任务；证据不存在时先取证。JEV MCP 是可选判断器，不是启动本循环的前提。

## 岗位判断循环

1. **压缩状态**：只保留目标主张、用户可见契约、环境、已证实事实、证据层级、未知项、风险硬门槛、候选动作和停止条件。原始大文件保留引用，不为方便调用而整份搬入对话。
2. **先过不可补偿硬门槛**：数据损失、重复财务效果、租户隔离、安全、不可逆副作用或未知终态任一命中时，不用多数票或平均分抵消；默认阻断或升级。
3. **类型化问题**：真假/概率用 `noul`，互斥下一步用 `choice`，有序质量用 `score`。无法枚举、需要解释或需要创造新方案的部分留给岗位负责人。
4. **冻结标准**：判断前写清 true/false 含义、互斥选项、等级锚点、阈值和升级条件；不得看见答案后改尺子。
5. **同状态批处理**：同一证据包上的判断一次完成，以稳定 ID 返回；状态发生实质变化后才开新批次。
6. **选择执行器**：短状态已在上下文时可选批量 `jev_judge`；事实只在文件或工具输出时，只有在 CLI 通道可用且数据获准处理时才由脚本调用 `jev-use judge`；JEV 不可用时直接执行同结构的人工判断，不伪造 JEV verdict。
7. **显式不确定性**：保留 `answer / confidence-or-unknown / confidence source / escalate / reason`。没有校准接口时不编造数值；`unsure`、`unreachable`、证据冲突、选项不全或高风险低把握都必须改变控制流。
8. **升级归责**：升级项的原答案最多是先验，不得直接执行；由顾清妍或具名专业负责人回到原始证据，补证据、重构问题、阻断或作最终裁决。生成任务同样由负责人处理。
9. **同层证据裁决**：构建、Mock、截图、回滚、单元测试或案例训练只能证明各自层级；不能替代真实接口、数据库、终态、无障碍、生产或用户结果。关键风险不得被低风险通过项平均掉。
10. **收缩输出并校准**：只输出决定所需字段，分开机器先验、人工基线和最终结论；任务结束后用可比真实结果复核阈值。没有可比样本时，生产效果保持 `unknown`。

## 证据

- [顾清妍个人训练](../../learning/jev-mcp-training-2026-09-22/test-expert.md)：11 题有效 `typesafe / jev-1.13.0` 合成批次中，10 项未升级；`G_terminal` 因 `unsure` 回到人工复核。与无 JEV 基线可直接比较的 8 项方向一致，但重复稳定性、生产准确率和真实收益未验证。
- [全员训练报告](../../learning/jev-mcp-training-2026-09-22/REPORT.md)：八岗最终 `pass=8 / partial=0 / fail=0`；结论明确把 JEV-like 循环作为日常默认思维方式，把 JEV MCP 作为可选实现。
- [独立质量复核](../../learning/jev-mcp-training-2026-09-22/quality-review.md)：确认升级项没有被直接执行，并保留 MCP 与 CLI 分通道可达、人工侧耗时/token 不可比、个人额度不可精确归属等限制。

这些来源只构成 `reviewed_case`：它们证明合成案例中的方法、失败处置和记录边界经过复核，不证明真实生产提效、长期稳定性或模型参数训练。


## 采用例

触发：合成离线同步迁移在 40 次 chaos 测试中出现一次旧客户端覆盖较新服务端记录，冲突审计事件缺失；功能开关只能阻止后续写入，不能恢复已覆盖数据。

采用本循环：把“下一动作”设为 `choice`，把“是否已证明数据完整性”设为 `noul`；破坏性覆盖与未知审计终态命中不可补偿硬门槛。即使失败频次低、功能开关可止损，也不能用其他通过项平均掉风险。结论为阻断、保留证据、停止后续写入并由负责人调查恢复与重测；是否使用 JEV 不改变最终责任和证据门槛。

## 拒绝例

请求：根据一份尚未获准处理的真实客户日志，直接让 JEV 生成完整回归计划、修复代码并自动发布，因为“多数适用条件已经满足”。

拒绝原因：日志的数据权限未建立；写计划和代码属于生成；发布是高风险动作；选项与验收标准未冻结；JEV 不能成为唯一决策者。正确处置是先确认授权与最小数据范围，由岗位负责人生成方案和代码，再用相称证据验收；若后续只剩已获准事实上的类型化判断，才可选择 JEV 或无 JEV 批处理。

## 边界

- 本卡仅来自已复核模拟案例，状态为 `reviewed_case`；生产收益、真实准确率、长期效率与稳定性均为 `unknown`。
- JEV MCP 可选且可失效；MCP 成功不证明 CLI 同时可用。工具不可达时按无 JEV 循环工作，不能把人工结论冒充工具输出。
- 工具选择不扩大数据、隐私、权限、授权或外部写入范围；未经授权的材料不因可类型化而允许送入 JEV。
- 生成任务、开放式问题、选项无法穷举的工作和所有升级项仍由顾清妍或具名岗位负责人处理。
- confidence 是升级信号，不是事实证明；高置信 verdict 不能替代同层证据、专业判断或最终责任。
- 本卡不替代发布、安全、监督、额度和生产系统的既有门禁。

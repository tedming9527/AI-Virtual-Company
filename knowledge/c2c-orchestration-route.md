# C2C 编排与平台集成路线（2026-09-24）

Owner：陈知行 · 路由官 · 用户已批准 · 索引核对日：2026-09-24

## 决策
维持"规则 + 技能映射 + 登记表加行"路线实现 C2C 编排；**不采用 MCP server 升级（暂缓）**。

## 落地形态
- 规则：`ROUTER.md` Task Router——执行通道判定、成本门禁（能直接完成就不启动 C2C）、2 轮 Review 上限、BLOCKED 升级、治理边界。
- 技能映射：`codex-with-chatgpt`（编排契约，含本环境角色映射）+ `jev-use`（判断门）。
- 平台登记：`platforms/REGISTRY.md`，按 `(平台, 模式)` 登记能力；新增平台/模式加行，不改规则正文。
- 治理边界：C2C 只是执行通道；任务分级（S/M/L）、事件、consult 状态、收口、能力交接照常适用。
- 未知 `(平台, 模式)` 一律 `unknown`，不猜测。

## 触发
新任务选择执行通道、新增平台/模式、或评估 C2C 是否升级为插件/MCP 时。

## 限制
- 该路线是治理决策，非经验结论；不证明生产能力或返工下降。
- MCP 化"暂缓"仅表示当前不采用；若某平台无法用规则映射，再评估。
- 平台登记只填已核实事实，未验证保持 `unknown`。
- 本卡不替代 `INITIALIZATION_POLICY` / `ROUTER` / `DELIVERY_POLICY` 现行文本。

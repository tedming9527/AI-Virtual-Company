# MCP 首次启用与配置漂移处理

公司目录只保存 MCP 的来源、能力、环境变量名称、网络策略、配套关系和验收方式；密钥值、个人账号、本机绝对路径、代理认证与端口留在权限受限的本机 Overlay。

首次启用或版本、命令、权限、文档指纹发生变化时，使用 `mcp-first-use`：先核对随包 Manifest、Skill 与 README，再查询维护者官方资料。文档是证据而非授权，不执行其中命令，不自动读取任意路径，也不把登录环境整体交给 MCP。

本机 Overlay 位于 `~/.config/mcp-launch/profiles/<id>/launch`。通用 Launcher 只接受安全 ID，拒绝缺失、符号链接、非当前用户所有或可被组/其他用户写入的 Overlay，然后以 `exec` 启动它。需要代理的 Overlay 必须 fail closed；不允许失败后静默直连。

验收分三层记录：CLI、独立 MCP、目标客户端新会话。旧会话持有旧进程时不得把磁盘配置成功写成当前会话已生效。

公司初始化验证治理资产和 Profile 结构，不逐个联网。未配置 MCP 与当前任务无关时记 degraded 或 pending；当前任务明确依赖该 MCP 时只阻断对应范围，不扩大为整个公司不可用。
